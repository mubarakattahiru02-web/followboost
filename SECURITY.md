# Security / Anti-Fraud

Use layered risk signals:
- Email verification
- Optional phone verification
- Device/app-installation risk signal
- IP and velocity checks
- CAPTCHA/bot protection
- Referral abuse detection
- Rate limits
- Suspicious-account review
- Admin audit logs
- No social-media passwords
- User-controlled social actions
- Verified payment webhooks before crediting purchased points

Device linking is a risk signal, not perfect proof of identity. Provide secure account recovery for users who change phones.
