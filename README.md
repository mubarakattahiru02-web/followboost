# FollowBoost
Real people. Real growth opportunities.

Starter project for a global social-growth platform: accounts, points, tasks, daily check-in, referrals, wallet, point purchases, admin dashboard, and anti-fraud structure.

This starter does not automate follows/likes/views/comments and does not collect social-media passwords. Social actions remain user-controlled and must comply with platform rules.

Production payment credentials, hosting, email/SMS verification, and official social-platform integrations still need to be configured.
